CLC Muttom Cherthala Website
===========================
Files:
- index.html
- style.css
- script.js

FREE HOSTING — NETLIFY
1. Create a free Netlify account.
2. Open the Netlify dashboard.
3. Use the option to add/deploy a site manually.
4. Drag the entire folder contents (index.html, style.css, script.js) into the deploy area.
5. Netlify will give you a free *.netlify.app web address.
6. You can rename the site from the Netlify dashboard.

FREE HOSTING — GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a public repository.
3. Upload index.html, style.css and script.js.
4. Open Settings > Pages.
5. Select the branch containing the files and save.
6. GitHub publishes the site at a github.io address.

CUSTOMIZATION
Replace the gallery placeholder blocks with your own photos and replace the text as needed.
For the CLC logo, place your logo file in the folder and update the brand section in index.html.
